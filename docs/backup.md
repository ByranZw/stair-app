# 账本备份与恢复

## 数据保存在哪里

- H5 调试：浏览器 IndexedDB。
- 安卓应用：应用私有 SQLite 数据库。
- 自选与行情缓存：设备本地保存，与账本独立。

浏览器与安卓不自动同步。应用不上传账户或交易数据；查询行情时只访问公开行情来源。

## 导出与迁移

在“我的 → 数据备份与恢复”导出账本 JSON，并将文件保存到应用之外。更换设备、卸载应用或清理数据前，先确认文件已保存。

备份包含账户、标的身份、已有持仓、资金流水、交易及投资计划和历史。自选列表和行情缓存不随账本迁移。

文件采用 `stair-book` 格式、`schemaVersion: 1`，最大 10 MB，带内容 SHA-256 校验。校验用于检查完整性，文件本身不加密，包含个人账目，请自行保管。

## 恢复

1. 选择备份文件，先预检格式、校验值及账本有效性。
2. 查看账户、持仓、成交、计划数量与现金合计。
3. 确认后整体替换当前账本，不合并两个设备的数据。

恢复时保留最近一次恢复前账本，可从“预检恢复前账本”再次检查并回退。它仍存于本机，卸载或清理应用后也会消失，不能代替外部备份文件。

恢复保留交易、成本、预算和手动暂停状态；观察高点与待执行提醒会清除，等待新行情重新判断。预检后若本机账本又有变更，需要重新预检。

当前文件导入、导出支持 H5 和安卓；iOS 文件能力尚未适配。
