# 策略、资金与图表口径

本文描述应用当前实现的计算方式。每个投资计划独立保存参数，修改一个计划不影响其他计划。

## 默认策略

| 参数           | 默认值 |
| -------------- | ------ |
| 预算份数       | 10 份  |
| 加仓跌幅       | 4%     |
| 止盈观察收益率 | 15%    |
| 高点回撤幅度   | 4%     |

预算金额由用户设置，每份金额为计划预算除以份数。

### 买入

首次买入由用户记录。之后以本轮上次实际买入价为基准：

```text
下一买点 = 上次实际买入价 × (1 − 加仓跌幅)
```

报价达到或低于下一买点、计划预算足够且无待确认交易时，提示加仓一份。一次跌穿多个档位也只提示一份；只有录入实际成交才改变持仓、现金和下一买点。

导入已有持仓不会自动生成买入记录。缺少上次实际买价时，不用持仓均价替代。

### 卖出

持仓报价达到单位成本对应的观察收益率后，计划进入止盈观察期，记录此后应用实际获取的报价高点：

```text
观察价 = 单位成本 × (1 + 止盈观察收益率)
回撤止盈价 = 已观察高点 × (1 − 高点回撤幅度)
```

报价回落到回撤止盈价时提示止盈。提醒不等于成交，卖出数量、成交价和费用仍由用户录入。全部卖出后该轮计划结束。

## 行情与提醒

策略在打开或返回应用、刷新有效报价时判断。招行黄金详情在页面可见且应用前台时约每 30 秒刷新；应用不提供后台交易监控或系统推送。

请求时间需在 15 分钟内，行情日期不早于当前中国市场日超过 7 个自然日。来源失败、非交易状态及不满足有效性要求的缓存不生成新判断。

- **ETF / 股票**：使用市场报价。股票支持沪深京 A 股、港股和美股。
- **场外基金**：使用披露的正式单位净值。
- **招行积存金**：加仓使用客户买入价，估值、观察高点和止盈使用客户卖出价。

## 账户资金

初始现金是账户基准日的现金，不是账户总资产。导入已有持仓时，初始现金不应重复包含这笔持仓价值；后续入金、出金通过资金流水记录。

```text
总资产 = 现金 + 已取得报价的持仓市值
可用现金 = 现金 − 待确认买入预留
计划待投入 = max(本轮预算 − 累计已确认买入金额（含费）− 本轮待确认买入预留, 0)
未分配资金 = 可用现金 − 活动计划待投入合计
```

无报价持仓会单独标记，其市值不计入已报价资产合计。

计划预算是软预留：只影响资金规划和超配提醒，不扣真实现金，也不禁止如实补录其他交易。暂停计划保留预留，已结束计划释放预留。未分配资金为负时代表预算缺口；不同账户之间不自动调拨。

卖出回款增加现金，但不回填本轮累计投入额度；导入旧持仓也不计作该轮新增买入预算消耗。

## 成本与收益

- 买入金额和费用计入成本；卖出到账扣除费用。
- 部分卖出按单位成本结转，最后清仓结转剩余成本。
- 现金分红按实际净到账增加现金及已实现收益，不冲减历史买入成本。
- 红利再投按确认金额增加成本和份额；拆分保持总成本，调整数量及单位成本。

金额与费用记到分，价格和数量最多 8 位小数，使用 decimal.js 进行十进制计算。更正或删除交易会重放后续流水，超卖等不合法结果不能保存。

## 图表与计划历史

ETF 使用未复权行情，场外基金使用正式单位净值；招行积存金走势使用上金所 Au99.99，招行当前买卖报价独立展示并用于策略判断。

图表提供成本线、下一买点和止盈线切换，积存金分时同样支持。参考线按对应日期的实际流水和已保存计划参数绘制；未进入观察期、没有有效高点时不画回撤止盈线。

B / S 是实际买卖价格，可点击查看记录；分时只标注填有成交时刻的记录。计划参数与提醒历史保留当时快照，不补造应用未观察到的高点或历史信号。

分红、再投和拆分按公告与实际确认记录入账。待核对权益会暂停相关策略，核对后由用户恢复；行情公告不代替实际到账记录。

## 港股与美股

成交价、走势图使用港币或美元，账户现金、成本、预算和收益统一人民币。记录买卖时填写实际人民币支出（含费）或到账（扣费），手续费也按人民币填写；导入已有持仓时填写人民币成本。

持仓和策略按报价附带的人民币汇率折算，汇率变化会参与4%判断；图表参考线按当前汇率换回原币。免费海外行情标注延迟，可得历史使用未复权价格；缺少有效分时的标的可查看日线。股票分红及拆分通过详情手动记录，海外每股分红及到账金额填写人民币。
