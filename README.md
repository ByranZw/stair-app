# 拾阶 · STAIR

<img src="app-icons/192.png" alt="拾阶图标" width="72" height="72">

一款践行 4% 定投策略的个人投资管理应用。管理 ETF、场外基金与招行积存金，把账户资产、计划预算、买卖记录和策略提醒放在一起。

基于 uni-app、Vue 3 和 TypeScript 开发，支持本地 H5 调试及安卓打包。账本保存在设备本地，无需部署业务服务端。

## 主要功能

- **账户总览**：查看持仓、收益、现金、计划预留与未分配资金，集中处理策略提醒和待确认交易。
- **投资计划**：每个计划独立配置预算、份数、加仓幅度和止盈参数，记录参数调整与执行历史。
- **自选与行情**：搜索 ETF、场外基金，添加招行黄金账户；查看行情、历史走势和实际成交 B/S 点。
- **交易记账**：记录买卖、资金转入转出、已有持仓及分红拆分，计算持仓成本和卖出收益；积存金支持克与元换算。
- **备份迁移**：导出、导入本地账本 JSON，在更换设备前保存完整交易和计划记录。

## 快速开始

环境：Node.js 22、npm。当前工程验证使用 Node.js 22.20.0。

```sh
git clone https://github.com/ByranZw/stair-app.git
cd stair-app
npm ci
npm run dev:h5
```

浏览器打开 <http://127.0.0.1:5178>。首次启动账本为空，可先创建账户，再添加自选、投资计划和实际交易。

```sh
npm run typecheck   # 类型检查
npm test            # 运行测试
npm run build:h5    # 构建 H5
npm run build:app   # 编译 App 资源
```

`build:app` 输出供原生打包使用的资源；生成安卓 APK 还需 HBuilderX 和签名配置，详见[构建指南](docs/build.md)。

## 数据与行情

账户和交易由用户录入，应用不登录银行或证券账户，也不自动下单。账本本地保存，行情查询需要联网；浏览器与安卓的数据通过备份文件迁移，不会自动同步。

- ETF：腾讯财经行情。
- 场外基金：东方财富正式单位净值，不使用盘中估值。
- 积存金：招行黄金账户买卖报价用于估值和策略判断；上金所 Au99.99 用于走势展示。

公开免费行情接口的可用性取决于来源网站。详细口径见[策略与资金说明](docs/strategy.md)，数据保存与迁移见[备份说明](docs/backup.md)。
