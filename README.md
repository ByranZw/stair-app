# 拾阶 · STAIR

一款践行 4% 定投策略的个人投资管理应用。管理股票、ETF、场外基金与招行积存金，把账户资产、计划预算、买卖记录和策略提醒放在一起。

## 下载安装

当前版本 **v0.1.14**，支持 **ARM64 安卓设备，Android 5.0 及以上**。

[下载 stair-0.1.14-arm64.apk](https://github.com/ByranZw/stair-app/releases/download/v0.1.14/stair-0.1.14-arm64.apk)

首次安装后，先创建账户，再添加自选、投资计划和实际交易。更新时可直接覆盖安装；更换设备或卸载应用前，请先导出账本备份。

本版允许负现金及超预算账本。更新前建议保留一份旧版备份；产生这类记录后，不要直接降级到 0.1.12 或更早版本，旧版可能拒绝读取或导入该账本。

从0.1.14开始，安卓安装版在启动/返回前台时每天最多检查一次GitHub正式版，发现新版显示可忽略的提示。也可进入“我的 → 检查更新”手动检查、查看说明、下载安装包。只有文件大小、SHA-256、应用及版本校验通过后才可确认安装；首次需在系统设置允许本应用安装来源，返回后再次确认。不静默安装、不强制更新，检查失败不影响记账。GitHub在部分网络下不可达时需稍后重试；无需登录或内置访问令牌。

发布仍使用 `v主.次.修订` 标签及 `stair-版本-arm64.apk` 文件名，上传正式Release并设为latest，同时上传含APK大小和SHA-256的 `update.json`。App优先读取Release附件清单，不占公共API查询额度；只有旧Release缺清单时回退一次API。预发布/草稿、缺失摘要、跨仓库链接及降级安装均不会作为可安装更新。

## 主要功能

- **账户总览**：查看持仓、收益、现金、计划预留与未分配资金，集中处理策略提醒和待确认交易。
- **日收益与涨跌**：持仓卡突出报价日的日收益、日涨跌幅，累计持仓收益保留在次行；自选显示日涨跌幅及全部账户合计日收益。金额隐藏同时覆盖自选收益。
- **投资计划**：每个计划独立配置预算、份数、加仓幅度和止盈参数，记录参数调整与执行历史。
- **自选与行情**：搜索沪深京 A 股、港股、美股、ETF 和场外基金，添加招行黄金账户；查看行情、历史走势和实际成交 B/S 点。
- **交易记账**：记录买卖、资金转入转出、已有持仓及分红拆分，计算持仓成本和卖出收益；积存金支持克与元换算。
- **数据维护**：直接搜索并导入已有持仓，成本价与总成本联动填写；支持修改、删除初始持仓和资金流水。
- **备份迁移**：导出、导入本地账本 JSON，在更换设备前保存完整交易和计划记录。

## 数据与行情

日收益按报价所属日计算：期末持仓市值 − 昨日持仓市值 + 当日卖出净收入 − 当日买入净支出，并计入已确认权益。买卖净额沿用账本实际值及手续费，不以现持仓直接乘整日涨幅。未持有不显示零收益；缺报价、缺昨日基准、当天导入、报价早于相关成交，或场内同日成交未填时间而无法判断先后时显示“—”。场外基金使用正式净值日及来源公布的日增长率。

港美股日收益按当前汇率统一折算人民币，标记“日收益估算”，不包含昨今汇率变动产生的完整汇兑收益。招行黄金账户缺少同侧昨收基准时，日涨跌及既有持仓日收益显示“—”，不借用上金所参考价代算。

账本保存在设备本地，无需注册应用账号。账户和交易由用户录入，应用不登录银行或证券账户，也不自动下单；查询行情需要联网。

拾阶是滞后记账工具，不做下单前验资。补记买入、场外申请、转出及更正历史记录时，不因账面现金不足或超过计划预算拒绝保存。现金按已录基准和流水计算，允许为负；不自动补造转入，也不把负值归零。未录全资金时，账面现金和总资产不等于银行实际余额；持仓成本和收益仍按真实成交计算。金额、数量、账户归属及持仓先后等数据一致性校验继续保留。

- 股票 / ETF：腾讯财经行情。港美股标注延迟，美股暂不提供分时，支持日线。
- 港美股：成交价保留原币，账户现金、成本和收益统一人民币；按实际人民币收支记账，持仓和策略按新浪汇率折算。
- 场外基金：东方财富正式单位净值，不使用盘中估值。
- 积存金：招行黄金账户买卖报价用于估值和策略判断；上金所 Au99.99 用于走势展示。
